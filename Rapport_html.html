Section 01

Identité du groupe

Notre groupe est constitué de 7 étudiants issus de différentes filières de l'IFRI (IA, IM, GL, SE&IoT, SI), conformément aux consignes du projet. Ce mélange de profils nous a permis d'aborder le problème sous des angles complémentaires : algorithmique, base de données, conception web et sécurité.

Le projet IFRI_MentorLink est une application web de mise en relation entre mentors et mentorés au sein de l'IFRI. Elle permet à chaque étudiant de créer un profil, de publier ou rechercher des offres et demandes de mentorat, et de communiquer via une messagerie intégrée.

Section 10

Algorithme de matching

L'algorithme calcule un score de compatibilité entre 0 et 100 pour chaque paire mentor-mentoré, selon trois critères pondérés.

Compétences (50 %)

Intersection entre les compétences maîtrisées du mentor et les lacunes du mentoré, normalisée sur le nombre de lacunes.

Disponibilités (30 %)

Nombre de créneaux horaires communs (jour + plage) divisé par le nombre de créneaux du mentoré.

Proximité filière (20 %)

Score maximal si même filière, réduit si filières différentes.

def calculer_score(mentor, mentore):
    # 1. Score compétences (50 %)
    lacunes      = set(mentore['lacunes'])
    competences  = set(mentor['competences'])
    intersection = lacunes & competences
    score_comp   = (len(intersection) / len(lacunes)) * 50 if lacunes else 0

    # 2. Score disponibilités (30 %)
    slots_mentor  = set(mentor['disponibilites'])
    slots_mentore = set(mentore['disponibilites'])
    communs       = slots_mentor & slots_mentore
    score_dispo   = (len(communs) / len(slots_mentore)) * 30 if slots_mentore else 0

    # 3. Score filière (20 %)
    score_filiere = 20 if mentor['filiere'] == mentore['filiere'] else 10

    return round(score_comp + score_dispo + score_filiere, 1)
Section 11

Instructions de déploiement

Prérequis : Python 3.10+, MySQL 8.0+, pip. Testé sur Windows 11.
1

Cloner le dépôt

git clone https://github.com/PIL1_2526_16/PIL1_2526_16.git
cd PIL1_2526_16
2

Créer la base de données MySQL

CREATE DATABASE ifri_mentorlink CHARACTER SET utf8mb4;
USE mentorlink;
SOURCE database/ifri_mentorlink.sql;
3

Installer les dépendances Python

pip install django mysqlclient python-dotenv
4

Configurer la base de données dans settings.py

DATABASES = {
  'default': {
    'ENGINE': 'django.db.backends.mysql',
    'NAME': 'ifri_mentorlink',
    'USER': 'root',
    'PASSWORD': 'votre_mot_de_passe',
    'HOST': 'localhost',
  }
}
5

Lancer le serveur Django

cd backend
python manage.py migrate
python manage.py runserver

L'application est accessible sur http://localhost:8000.

Section 12

Manuel d'utilisation

S'inscrire

1

Informations personnelles

Remplir nom, prénom, email, téléphone, filière, niveau et mot de passe. L'email et le téléphone doivent être uniques.

2

Compétences & lacunes

Sélectionner les matières maîtrisées (points forts) et celles où on a besoin d'aide parmi les compétences du curriculum IFRI.

3

Disponibilités

Cocher les créneaux horaires habituellement disponibles par jour de la semaine.

Trouver un mentor / mentoré

  • Aller sur la page Matching depuis le tableau de bord
  • Utiliser la barre de recherche pour filtrer par matière ou compétence
  • Filtrer par type (offre / demande) ou format (présentiel / en ligne)
  • Consulter le score de compatibilité affiché sur chaque carte
  • Cliquer sur Contacter pour envoyer un message via la messagerie

Publier une offre ou une demande

  • Cliquer sur Publier une offre ou Publier une demande depuis la page Matching
  • Sélectionner les matières concernées, les disponibilités et le format souhaité
  • Valider : l'annonce est immédiatement visible pour les autres utilisateurs

Messagerie

  • Accéder à Messages depuis la barre de navigation
  • Sélectionner une conversation dans la liste à gauche
  • Taper et envoyer des messages textuels
  • L'historique complet des conversations est conservé
